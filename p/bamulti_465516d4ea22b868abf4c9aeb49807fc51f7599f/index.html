Salvador implanta novo sistema para agilizar abertura de empresas a partir de setembro

A partir de setembro, Salvador começará a utilizar o REGIN 2.0, sistema que integra órgãos públicos para acelerar o processo de legalização empresarial, inicialmente para atividades de baixo risco.

A expectativa é reduzir o retrabalho, diminuir intervenções manuais e evitar inconsistências entre bases de dados.

Com a implantação do novo sistema, o tempo médio de análise dos processos municipais para abertura de empresas deve cair para menos de uma hora, colocando Salvador entre as capitais mais ágeis do país nesse procedimento. Atualmente, a Juceb já figura entre as juntas comerciais mais rápidas do Brasil, com análise em poucos minutos no âmbito estadual.

Além disso, a Juceb pretende utilizar os módulos de Business Intelligence do sistema para acompanhar automaticamente as demandas municipais e avaliar os efeitos da desburocratização no ambiente de negócios. A autarquia já utiliza ferramentas como o Painel de Empresas para monitorar dados de registros e abertura de negócios na Bahia.

Essa iniciativa utiliza dados de registro e atividades econômicas para subsidiar planos de negócios e monitorar o crescimento do número de novas empresas no estado.

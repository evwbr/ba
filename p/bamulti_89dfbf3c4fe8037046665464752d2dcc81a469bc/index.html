João Roma destaca importância de alianças amplas para mudança política na Bahia

João Roma, candidato na chapa de ACM Neto, ressaltou a necessidade de articulações políticas para viabilizar um projeto de transformação no estado da Bahia.

Durante evento político, João Roma enfatizou a estratégia de formar frentes amplas para as disputas eleitorais, destacando que o alinhamento entre diferentes forças é fundamental no processo eleitoral.

O político afirmou que cada candidatura deve buscar a maior aliança possível para fortalecer seu projeto, citando como exemplo a ampla coalizão construída na Bahia.

Roma ressaltou que a união de diversos vetores políticos é essencial para trabalhar em conjunto e promover mudanças significativas no estado.

O candidato reforçou que o objetivo é consolidar uma base sólida que permita implementar transformações efetivas na Bahia, contando com o apoio de múltiplas forças políticas.

Secretaria de Políticas para Mulheres recebe inscrições para curso preparatório gratuito ao Enem

A Secretaria Municipal de Políticas para Mulheres, Infância e Juventude recebe até esta quinta-feira, 28, as inscrições presenciais para o curso preparatório gratuito ao Enem destinado a jovens de famílias de baixa renda.

O curso intensivo faz parte do projeto Ingressar, que oferece um curso pré-Enem 100% gratuito para estudantes que desejam se preparar para o exame nacional.

As inscrições devem ser feitas presencialmente na sede da Secretaria, localizada na Rua Estados Unidos, 397, Condomínio Cidade de Salvador, 5º andar, das 9h às 16h. Os candidatos precisam apresentar documentação específica para comprovar a elegibilidade.

Entre os documentos exigidos estão comprovante de beneficiário do Programa Bolsa Família, solicitação de cadastramento assinada pelos pais ou responsáveis para menores de idade, auto declaração étnico-racial para afrodescendentes, declaração para pessoas com deficiência e comprovante de inscrição no Enem 2026.

Também são aceitas declarações para integrantes dos projetos sociais da Fundação Cidade Mãe, Sinaleiras e Cidadão Aprendiz, emitidas pelas respectivas instituições. O edital do processo seletivo disponibiliza modelos para as declarações necessárias.

O projeto visa atender jovens em situação de vulnerabilidade social, oferecendo uma oportunidade de qualificação para o Enem e, consequentemente, para o ingresso no ensino superior.

A entrega da documentação completa é requisito obrigatório para a participação no curso, que reforça o compromisso da prefeitura com a inclusão educacional e o apoio a estudantes de baixa renda.

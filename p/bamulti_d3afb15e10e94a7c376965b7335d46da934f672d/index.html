Bahia mantém exigência financeira para liberar atacante Kike após mudança de justificativa para ausência

Atacante Kike apresentou diferentes justificativas para ausência em jogo do Bahia, mas clube só aceita liberá-lo mediante compensação financeira considerada satisfatória.

O jogador Kike ficou fora da partida contra a Chapecoense inicialmente alegando questões pessoais. Depois, a justificativa para a ausência mudou para um problema no tornozelo.

Exames realizados pelo departamento médico do Bahia não identificaram qualquer lesão no atleta, que foi considerado clinicamente apto para retornar às atividades normalmente.

O pedido de liberação do atacante foi comunicado ao Bahia, que mantém a posição de só liberar o jogador mediante uma compensação financeira considerada satisfatória.

A sequência dos acontecimentos evidencia uma mudança de postura do atleta, que passou de justificativas pessoais para uma suposta lesão não confirmada pelos exames médicos.

O Bahia segue firme na exigência financeira para liberar Kike, sem ceder às solicitações do jogador até o momento.
